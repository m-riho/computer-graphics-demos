# 第3回：投影とモデリング変換

このディレクトリの9ファイルはUIを含まない短い実験です。`runExample()`に具体的な入力を与え、共有関数の結果を読みます。公開コードページでは関数本体も確認できます。

## 座標と行列の約束

- 右手系。カメラは−Zを見る。正の奥行きd=−z_camera。
- 点は列ベクトル。4×4行列は行優先（row-major）の16要素で格納するが、行ベクトルではない。
- M=TRはp′=T(Rp)：右側の変換を先に適用する。
- 角度の入力単位は度。内部でラジアンへ換算する。
- 点の同次座標は(x,y,z,1)。非正規・非有限の行列入力は例外で拒否する。
- 透視投影はNDCのx,yを返す。d<nearやカメラ背面はnullとし、割り算を行わない。視野外の点はNDCの±1を超えうる。
- ビューポート変換で左上原点・Y下向きの画面座標へ変換する。
- ワイヤーフレームの端点がnearより手前にある辺は表示しない簡略化。完全なポリゴンクリッピングや隠面消去を実装したものではない。
- カメラ変換と物体変換の比較は、同じFOVで比較対象全体に対応する変換を適用した場合。固定された背景や照明まで同じになるという意味ではない。
