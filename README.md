# CGを、触って学ぶ。

コンピュータグラフィックスを学ぶ、日本語のインタラクティブ教材です。トップの授業回一覧から、各回のテーマ一覧へ進みます。教材は授業の進行に合わせて追加します。

各テーマに2つの入口があります。
- **操作して理解する**：値を変え、画像や数値の変化を観察します。
- **コードで理解する**：短いTypeScriptの実験と、その場で計算した結果を読みます。「計算の実装も読む」で同じ関数の本体を確認できます。

現在の第2回で扱うテーマ：錐体応答、RGB加法混色、アルファ値と画像の合成、RGB/HSV、標本化定理とエイリアシング（回転・縞・斜め線）、標本化、量子化、ガンマ、エイリアシング、JPEG圧縮、トーンマッピング。

現在の第3回（2026年10月16日）：平行・透視投影、点の投影、奥行きの描き方の発見、Cavalier/Cabinet、座標変換パイプライン、4×4行列、行列とベクトルの掛け算、基底の移り先と線形写像、変換順序、カメラと物体の変換。10テーマ・20ページです。発見教材の式・名称・コードは観察後に開く方式です。

第4回（2026年10月23日）はモデリングその1です。Wireframe / Surface / Solid、Meshの接続、Half-edge、Manifold、Boolean / CSG、Sweep、Bevel / Fillet、4方式のSubdivision、Euler characteristicの9テーマ・18ページを用意しています。`#/sessions/04`から選択できます。

## ローカルで動かす

Node.js 22.18以降（24 LTS推奨）とnpmを用意します。

```sh
npm ci
npm run dev
```

表示されたURL（通常 http://127.0.0.1:3040）を開きます。コードは `examples/02-color-image/`、実際に共有する関数は `packages/cg-algorithms/src/` にあります。実験の入力値を変更すると、コードページの実行結果も変わります。

```sh
npm test
npm run build
npm run preview
```

## GitHub Pages

この教材専用のリポジトリで、Settings → Pages → Sourceを **GitHub Actions** にします。既定ブランチを `main` にすると、付属workflowがテスト・ビルド・公開を実行します。リポジトリ名のサブパスはPagesの設定から取得します。URLの `#/sessions/02` は第2回の一覧、`#/sessions/02/テーマ/demo` と `#/sessions/02/テーマ/code` は各教材です。直接開いても使えます。初版の `#/テーマ/demo`・`#/テーマ/code` も第2回のリンクとして利用できます。

## 教材の近似

錐体応答は実測値ではなく模式曲線です。ガンマのべき乗モデルと実際のsRGBを区別しています。JPEGの8×8実験は量子化の説明用で、完全なエンコーダではありません。画像はプログラムで生成しており、写真や外部データの取得は不要です。
